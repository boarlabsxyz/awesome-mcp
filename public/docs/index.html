Getting started

Awesome MCP documentation

Connect a service once, paste one URL into Claude, and your assistant can use it. This page is the five-minute version; the rest of these docs are the details.

What this is

Awesome MCP is a hosted Model Context Protocol server. You connect a service once — Google Workspace, Slack, ClickUp, Outline, PeopleForce or HubSpot — and get back a URL. Paste that URL into Claude (or any MCP-compatible assistant) and the assistant can use that service on your behalf.

Nothing runs on your machine. Your credentials stay on the server; the assistant only ever sees the tools, never the tokens.

Quickstart

  1. Sign in. Go to the dashboard and sign in — with Google, or with an email and password. The first sign-in creates your account.
  2. Add a tool. Click + Add Tool and pick a service. You will either be sent through that provider’s OAuth consent screen, or asked to paste an API token — see Connect a connector for which is which.
  3. Copy the URL. Each connected instance gets its own Copy URL button. That URL already contains your credentials, so treat it like a password.
  4. Add it to Claude. In Claude, add the URL as a custom connector. See Add to Claude for the exact steps in Claude.ai, Claude Desktop and Claude Code.
  5. Ask for something. “What’s on my calendar tomorrow?” is a good first test — it proves the connection without changing anything.
Treat the URL as a secret

The MCP URL embeds your API key as a query parameter. Anyone who has it can use your connected services. Do not paste it into a shared document, a ticket, or a public channel. If it leaks, delete the instance from the dashboard and connect again.

  • HubSpot Contacts, companies, deals and tickets.
