Connectors

Slack

There are two Slack connectors. One acts as you, one acts as a bot, and choosing the right one is most of the setup.

Slack appears twice in the catalog, and the difference matters more than the names suggest.

Which one to use

Slack MCPSlack Bot MCP
Acts asYouA bot user
SetupOne click, approve in SlackCreate a Slack app yourself, paste a token
SeesEverything you can see, including DMsOnly channels the bot was invited to
Per-channel access rulesYesNo
SearchYesNo — Slack does not allow bots to search

Use Slack MCP for personal assistance over your own workspace. Use Slack Bot MCP when you want a clearly-identified bot posting to specific channels and nothing else.

Connecting Slack MCP

  1. Click + Add Tool and pick Slack MCP.
  2. Approve in Slack.
  3. The access-rules dialog opens automatically. Set it up before you use the connector.

Access rules

Because this connector acts as you, it can reach every channel and DM you can. Access rules narrow that: allow only certain channels, or block specific ones.

The rules are re-read on every call, so tightening them takes effect immediately — including for message history that was already captured. They also apply to search: results from channels you have excluded are dropped before you see them, and the response tells you how many were hidden rather than pretending Slack found nothing.

Connecting Slack Bot MCP

  1. Create a Slack app in your workspace.
  2. Add these bot scopes: channels:history, channels:read, groups:history, groups:read, chat:write, users:read, files:read.
  3. Install the app to the workspace and copy the Bot User OAuth Token (it starts with xoxb-).
  4. Paste it into the dashboard.
  5. Invite the bot to each channel you want it to work in, with /invite. A bot that has not been invited sees nothing, and this is the single most common reason a freshly-connected bot appears to do nothing.

Files and images

Attachments appear under each message with a file id, and Claude can fetch them — either to look at, or as a public URL to hand to another connector. See the images page.

Connected before file support? Reconnect.

If files come back as “file hidden”, or search does not work, your connection was made before those permissions were added. Press Reconnect on the dashboard and approve again. Nothing else is lost — your access rules and your MCP URL survive.

Watching channels

You can subscribe to events in a channel — new messages, reactions — and read back what happened since. As with ClickUp, this is a record you ask about rather than something that arrives on its own.

Delivery depends on how the Slack app is configured for the whole workspace, which is an administrator setting. If a subscription looks healthy but never captures anything, there is a diagnostic tool that can tell you whether Slack has ever delivered an event, whether it was rejected, or whether it arrived and simply did not match — ask Claude to debug the subscription.

Try asking

  • “Summarize what I missed in #eng-platform today”
  • “Send a release note to #announcements”
  • “Find the thread where we agreed on the API shape”
