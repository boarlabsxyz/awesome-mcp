Getting started

Add to Claude

You have a URL from the dashboard. Here is where it goes in each Claude client, and how to tell whether it took.

The URL

Every connection on the dashboard has its own URL, which you get from its Copy URL button. It looks like this:

https://app.awesome-mcp.xyz/calendar?apiKey=YOUR_KEY.INSTANCE_ID

The path (/calendar, /sheets, /clickup…) identifies the service. The query parameter is your credential: your account API key, a dot, and the id of this particular connection. That is how one key can drive several connections to the same service.

This URL is a credential

Anyone holding it can use your connected account. Do not paste it into a shared doc, a ticket, or a screenshot. If it leaks, delete that connection from the dashboard — the URL dies with it — and connect again.

Claude.ai

  1. Open Settings → Connectors.
  2. Choose Add custom connector.
  3. Paste the URL you copied from the dashboard.
  4. Save, then start a new chat and ask for something the connector can do.

Claude Desktop

Claude Desktop reads a JSON config file. Add an entry under mcpServers:

{
  "mcpServers": {
    "google-calendar": {
      "url": "https://app.awesome-mcp.xyz/calendar?apiKey=YOUR_KEY.INSTANCE_ID"
    }
  }
}

The key (google-calendar above) is just a label you choose; it is how the server shows up in Claude. Restart Claude Desktop after editing the file.

Claude Code

From a terminal:

claude mcp add --transport http awesome-calendar "https://app.awesome-mcp.xyz/calendar?apiKey=YOUR_KEY.INSTANCE_ID"

Then confirm it registered:

claude mcp list

Quote the URL. It contains ? and &, which your shell will otherwise interpret.

Check that it worked

Ask for a read, not a write — it proves the connection without changing anything:

  • Calendar — “What’s on my calendar tomorrow?”
  • Slack — “Summarize what I missed in #general today.”
  • Google Drive — “Find the latest version of the pricing memo.”
  • HubSpot — “Find the Acme Corp company and summarize its recent activity.”

“MCP Not Connected”

If Claude shows an MCP Not Connected page instead of working, the order was wrong: the connector has to be connected on the dashboard before it is added to Claude. Go back to the dashboard, connect that service, then retry in Claude.

Other failure modes are on the troubleshooting page.
