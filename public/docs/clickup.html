Connectors

ClickUp

Tasks, Docs, time tracking and event history. Connecting is one click; uploading images needs one extra setting in Claude.

Tasks, lists, folders and spaces; Docs and pages; comments, tags, custom fields and time tracking.

Connecting

  1. On the dashboard, click + Add Tool and pick ClickUp MCP.
  2. You are sent to ClickUp to authorize. Choose the workspace you want to grant access to.
  3. Approve, and you are returned to the dashboard with the connection in place.

The connection inherits your own ClickUp permissions — it can see exactly what you can see, nothing more.

Uploading images to Docs

One-time setup in Claude

Before Claude can put an image into a ClickUp Doc, open Settings → Capabilities in Claude, scroll to Domain allowlist, and add clickup.awesome-mcp.xyz. Full explanation on the images page.

Searching Docs

ClickUp’s API has no text search for Docs, so searching scans the workspace page by page and filters locally. Two consequences worth knowing:

  • A search always tells you how much it scanned. If a doc is not found, the answer distinguishes “it is not there” from “the scan stopped early”.
  • Title matching requires every word you type to appear, in any order. ClickUp titles are punctuation-heavy, so AWESOME Sync matches [AWESOME] Sync - 08/15/2026.

Watching for changes

You can subscribe to task events in a list and read back what happened since. This is a record you ask about, not a notification that arrives on its own — nothing gets pushed into a conversation. It saves you paging through a list and keeping track of what you already saw.

Try asking

  • “Create a task in the “Backlog” list with today's sync notes”
  • “What's assigned to me and due this week?”
  • “Comment on CU-86c9mr5kd with the latest status”
