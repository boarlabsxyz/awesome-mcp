Outline Wiki

Read and write wiki documents and collections. Because Outline is self-hosted, you supply the address of your instance along with the credential.

Outline is a self-hosted wiki, so this connector needs to know which wiki as well as who you are.

Connecting

There are two possible flows, and which one you see depends on whether an administrator has registered an OAuth application on your Outline instance.

Pasting an API key

This is the usual case.

  1. Click + Add Tool and pick Outline Wiki MCP.
  2. In Outline, go to Preferences → API and Access → New API Key and create a key. It starts with ol_pat_.
  3. Back in the dashboard, enter the URL of your wiki — for example https://wiki.example.com, with no trailing slash — and paste the key.

The key is scoped to your own Outline user, so the connector can reach exactly the collections you can. You can revoke it in Outline at any time; doing so breaks the connection immediately, and you can supply a replacement with Re-enter token without re-adding the connector in Claude.

Approving via OAuth

If your administrator has registered an OAuth application, picking Outline sends you straight to your wiki’s consent screen instead, and there is no key to create or paste.

Try asking

  • “Find the onboarding doc in the Engineering collection”
  • “Create a doc summarizing today's incident in the Runbooks collection”
  • “Search the wiki for our deployment checklist”

The connector can create, update and delete documents and collections, not just read them.
