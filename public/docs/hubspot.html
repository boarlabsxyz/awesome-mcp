Connectors

HubSpot

CRM reads and writes over OAuth. If you connected before deal support existed, start with the reconnect note below.

Contacts, companies, deals, tickets, properties and activity — reads and writes.

Connecting

  1. Click + Add Tool and pick HubSpot MCP.
  2. Choose Connect with HubSpot and approve in HubSpot, selecting the portal you want.

If your deployment has not been configured with a HubSpot application you will be asked for a private-app token instead — create one under Settings → Integrations → Private Apps, granting read scopes for lookups and write scopes for anything that creates or updates records.

Deals need a reconnect

If deal lookups fail, this is why

Permission to read deals was added after this connector first shipped, and a token only ever holds the permissions it was granted when it was created. If you connected HubSpot before that, every deal request is refused — while the connection continues to look completely healthy, because HubSpot tokens do not expire in a way the dashboard can detect.

Press Reconnect on the dashboard and approve again.

If it still fails afterwards, the missing permission is in the HubSpot application or portal configuration, not in your consent — reconnecting again will not help. The error message distinguishes these two cases: it lists both what was needed and what your token actually holds.

Note that a company record shows how many deals it has without granting any access to them. Seeing a deal count and then getting nothing back is that, not a bug.

What to expect from the answers

  • Asking for specific properties that HubSpot does not return is flagged explicitly, so “this record has no value” is never confused with “the connector cannot see that field”.
  • Counts from a large scan are reported as a floor — “25+” rather than “25” — when the scan hit its limit, so a partial result never reads as a complete pipeline.
  • After an update, the record is re-read, so what you are shown is the record as it now stands rather than HubSpot’s partial echo of the change.

Activity and email bodies

Company activity covers notes, calls and meetings. Email bodies need an additional permission; if emails come back empty while meetings and calls are fine, that permission is missing — reconnect.

Logging activity

Claude can create notes and tasks and log calls and meetings against a record, and delete them again. A deletion archives the engagement — it disappears from the timeline but is recoverable from HubSpot’s recycling bin, which makes these safe to try on a real portal.

Try asking

  • “Find the Acme Corp company and summarize its recent activity”
  • “Update the lifecycle stage for contact jane@acme.com”
  • “List open tickets modified this week”
